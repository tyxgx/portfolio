liveflights - Architecture

Real-time flight intelligence platform: serverless on AWS, defined in Terraform, running for about $2 a month.

ComputeMLS3 storageAPIExternal / clientOps
  • Live on AWS (us-east-1): a scheduled Lambda ingests real flight positions every minute; a separate predict Lambda serves a PyTorch GRU (ONNX) that predicts each aircraft 5 minutes ahead and scores itself against reality.
  • Train/serve skew is prevented structurally: one shared features.py module is imported identically by the offline training script and the live predict Lambda.
  • About 3,500 aircraft from 50+ countries at a time. Median live error about 1-1.5 km over recent days; traffic forecast hourly MAE 86 flights vs 568 for a naive baseline.
  • A separate local lakehouse (Docker Compose: Redpanda, Spark Structured Streaming, Delta bronze/silver/gold, dbt, 4 Airflow DAGs) is verified in GitHub Actions CI; it is not part of the live AWS path.
