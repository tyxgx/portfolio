StreamPulse - Architecture

Daily Spotify chart analytics for 72 markets: a medallion data lake on S3, a static dashboard, and a LangGraph chatbot on Lambda.

ComputeChatbotS3 / DynamoDB storageCI / CDExternal / clientOps
  • Serverless on AWS (ap-south-1), no always-on servers: S3 website for the dashboard, one Lambda container for the chatbot, DynamoDB for rate limits, all defined in Terraform.
  • Bronze keeps every version of every raw row, so a correction from Kaggle never overwrites history; Silver and Gold can be rebuilt from Bronze at any time.
  • The chatbot never invents numbers: the model only phrases results returned by 10 deterministic tools, and a verifier rejects any figure that no tool returned.
  • Numbers are charted streams (tracks on a market top-200 chart), not total Spotify streams. The site is served over HTTPS from the S3 REST address (CloudFront was not available on the account).
